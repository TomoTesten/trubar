CIVILNO PROCESNO PRAVO - ODŠKODNINSKO PRAVO

predlog za dopustitev revizije - višina odškodnine za nepremoženjsko škodo - pravica do zdravega življenjskega okolja - hrup - odstop od sodne prakse - dopuščena revizija

Pogoji za dopustitev revizije glede pravnega vprašanja višine odškodnine so izpolnjeni.

Predlogu se ugodi in se revizija dopusti glede vprašanja višine odškodnine.

1. Sodišče prve stopnje je tožnikoma zaradi kršitve pravice do zdravega življenjskega okolja prisodilo vsakemu po 8.000 EUR odškodnine. Pritožbeno sodišče je tako odločitev potrdilo.

2. Tožena stranka je predlagala dopustitev revizije zoper sodbo sodišča druge stopnje glede vprašanja višine revizije zaradi zatrjevanega odstopa od sodne prakse oziroma zaradi zagotovitve njene enotnosti. Meni, da je odškodnina, pravnomočno prisojena vsakemu od tožnikov, previsoka za 3.000 EUR.

4. Pogoji za dopustitev revizije iz prvega odstavka 367.a člena Zakona o pravdnem postopku glede pravnega vprašanja višine odškodnine so izpolnjeni. Vrhovno sodišče je zato predlogu ugodilo in revizijo dopustilo.
