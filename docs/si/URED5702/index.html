Uredba o dopolnitvi Uredbe o razvrstitvi prepovedanih drog

Na podlagi drugega odstavka 2. člena Zakona o proizvodnji in prometu s prepovedanimi drogami (Uradni list RS, št. 108/99, 44/00, 2/04 – ZZdrI-A in 47/04 – ZdZPZ) izdaja Vlada Republike Slovenije

U R E D B O

o dopolnitvi Uredbe o razvrstitvi prepovedanih drog

1. člen

V Uredbi o razvrstitvi prepovedanih drog (Uradni list RS, št. 49/00, 8/01 – popr., 49/01, 78/02, 53/04, 122/07, 102/09 in 95/10) se v seznam skupine I. za zaporedno številko 64 doda nova zaporedna številka 65, ki se glasi:
»

+----------------+-------------------+--------------------------+
| Zaporedna | Prepovedana droga | Kemijsko ime |
| številka | | |
+----------------+-------------------+--------------------------+
| 65. |MEFEDRON |4-metilmetkatinon |
| | | |
| | |C(11)H(15)NO |
| | |M(r) = 177,242 |
+----------------+-------------------+--------------------------+

«.
Zaporedne številke prepovedanih drog skupine II. in III. se ustrezno preštevilčijo.

2. člen

Ta uredba začne veljati petnajsti dan po objavi v Uradnem listu Republike Slovenije.
