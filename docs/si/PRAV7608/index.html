Pravilnik o določitvi višine dodatka za dvojezičnost direktorjev s področja kmetijstva, gozdarstva in prehrane

Na podlagi četrte alineje 9. člena Uredbe o plačah direktorjev v javnem sektorju (Uradni list RS, št. 73/05, 103/05 in 12/06) izdaja ministrica za kmetijstvo, gozdarstvo in prehrano

P R A V I L N I K

o določitvi višine dodatka za dvojezičnost direktorjev s področja kmetijstva, gozdarstva in prehrane

1. člen

S tem pravilnikom se določa višina dodatka za dvojezičnost direktorjev na področju kmetijstva, gozdarstva in prehrane (v nadaljnjem besedilu: direktorji), ki delajo na območjih občin, v katerih živita italijanska ali madžarska narodna skupnost, kjer je italijanski ali madžarski jezik tudi uradni jezik.

2. člen

(1) Direktorjem pripada dodatek za dvojezičnost v naslednji višini:

+-------------+-------------------------+---------------+-------------------+
| Šifra | Tip osebe javnega prava | Ime delovnega | Dodatek za |
| delovnega | | mesta | dvojezičnost |
| mesta | | | v % od osnovne |
| | | | plače |
| | | | |
+-------------+-------------------------+---------------+-------------------+
|B017375 |Kmetijsko gozdarska |Direktor KGZ | 4% |
| |zbornica (KGZ) | | |
| | | | |
+-------------+-------------------------+---------------+-------------------+

(2) Namestniku direktorja, strokovnemu direktorju, članu uprave ali strokovnemu vodji pripada dodatek iz prejšnjega odstavka v enaki višini.

3. člen

Ta pravilnik začne veljati naslednji dan po objavi v Uradnem listu Republike Slovenije.
