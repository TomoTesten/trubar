Sklep o spremembah sklepa o izdajanju blagajniških zapisov Banke Slovenije

Na podlagi 4. točke 25. člena, 29. člena ter drugega odstavka 20. člena zakona o Banki Slovenije (Uradni list RS, št. 1/91-I) izdaja Svet Banke Slovenije

SKLEP

o spremembi sklepa o izdajanju blagajniških zapisov Banke Slovenije

  1. V sklepu o izdajanju blagajniških zapisov Banke Slovenije (Uradni list RS, št. 28/91-I) se črta drugi odstavek 2. točke.
  2. Ta sklep začne veljati z dnem objave v Uradnem listu Republike Slovenije.

Št. DP 15-1/92

Ljubljana, dne 16. januarja 1992.
