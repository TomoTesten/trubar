Sklep o prenosu delov državnih cest med občinske ceste

Na podlagi četrtega odstavka 43. člena Zakona o cestah (Uradni list RS, št. 109/10, 48/12, 36/14 – odl. US, 46/15 in 10/18) je Vlada Republike Slovenije sprejela

o prenosu delov državnih cest med občinske ceste

I

Deli državnih cest iz II. do V. točke tega sklepa, ki so bili z Uredbo o kategorizaciji državnih cest (Uradni list RS, št. 102/12, 35/15, 38/15, 78/15, 21/16, 52/16, 64/16, 41/17, 63/17 in 78/19) opredeljeni kot deli kategoriziranih državnih cest, se prenesejo med občinske ceste.
