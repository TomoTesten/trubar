- katastrski občini Slape, M1 : 1000: parcelna številka ’434/1, 479/4, 526/2, 528/2’,
- katastrski občini Zadobrova, M1 : 2880: parcelna številka ’1405/3’,

- katastrski občini Podgorica, M1 : 2880: parcelna številka ’788’.
