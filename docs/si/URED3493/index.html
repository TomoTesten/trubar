o spremembah Uredbe o ureditvi trga
s poljščinami

1. člen

V Uredbi o ureditvi trga s poljščinami (Uradni list RS, št. 22/04 in 83/04) se povsod v prvem in drugem odstavku 4. člena znesek »66.957 SIT/ha« nadomesti z zneskom »67.275 SIT/ha«.

2. člen

3. člen

4. člen
