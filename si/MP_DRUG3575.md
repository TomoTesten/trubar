# Poročilo o izidu glasovanja na referendumu (Ljutomer) (DRUG)

Na podlagi 12. člena Zakona o referendumu in o drugih oblikah osebnega izjavljanja (Uradni list SRS, št. 23/77, 18/88 in 8/90) volilna komisija Krajevne skupnosti Razkrižje objavlja


## POROČILO
o izidu glasovanja na referendumu za uvedbo krajevnega samoprispevka za 1. območje Krajevne skupnosti Razkrižje, ki obsega naselja Gibina, Razkrižje, Šafarsko in Veščica ter 2. območje Krajevne skupnosti Razkrižje, ki obsega naselja Globoka, Kopriva in Šprinc.

Na referendumu, ki je bil izveden v nedeljo 18. 4. 1993 so bili doseženi naslednji glasovalni rezultati:

| Volilno        | štev.     |           | neveljav. | glasov.  | glasov.   |
|                | volil.    | glasovalo |           |          |           |
| območje        | upravičen.|           | glasovnic | ZA       | PROTI     |
+----------------+-----------+-----------+-----------+----------+-----------+
| 1. Gibina,     | 854       | 769       | 4         | 611      | 154       |
| Razkrižje,     |           | (90,05%)  |           | (71,55%) | (18,03%)  |
| Šafarsko,      |           |           |           |          |           |
| Veščica        |           |           |           |          |           |
| 2. Globoka,    | 259       | 222       | 3         | 202      | 17        |
| Kopriva, Šprinc|           | (85,71%)  |           | (77,99%) | (6,56%)   |
+----------------+-----------+-----------+-----------+----------+-----------+

Volilna komisija Krajevne skupnosti Razkrižje ugotavlja, da je referendum izveden v skladu z zakonom in da je za uvedbo krajevnega samoprispevka na območju, ki obsega naselja Gibina, Razkrižje, Šafarsko in Veščica glasovalo 71,55%, na območju, ki obsega naselja Globoka, Kopriva in Šprinc pa 77,99% od skupnega števila volilnih upravičencev vpisanih v volilni imenik.
Krajevni samoprispevek je tako na obeh območjih sprejet.

Razkrižje, dne 18. aprila 1993.
