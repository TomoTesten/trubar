# Pravilnik o spremembah Pravilnika o sprejemu otrok v vrtec (PRAV)

Na podlagi 20.f člena Zakona o vrtcih (Uradni list RS, št. 100/05 – UPB2, 25/08, 98/09 – ZIUZGK, 36/10, 62/10 – ZUPJS, 94/10 – ZIU, 40/12 – ZUJF113), 18. in 104. člena Statuta Mestne občine Kranj (Uradni list RS, št. 33/07) je Svet Mestne občine Kranj na 4. seji dne 18. 2. 2015 sprejel


## P R A V I L N I K
o spremembah Pravilnika o sprejemu otrok v vrtec


### 1. člen

V Pravilniku o sprejemu otrok v vrtec (Uradni list RS, št. 17/14 – uradno prečiščeno besedilo UPB2) se spremeni 6. zaporedna številka 28. člena pravilnika in se po novem glasi:

|     |    |variant)                                     |      |

|     | a) |Otrok, ki je bil v preteklem šolskem letu    |  12  |
|     |    |uvrščen na centralni čakalni seznam, pa mu   |      |
|     |    |med šolskim letom ni bilo ponujeno prosto    |      |

### PREHODNE IN KONČNE DOLOČBE


### 2. člen

Sprememba iz 1. člena tega pravilnika se prične uporabljati pri vpisu otrok v vrtec za šolsko leto 2015/2016 in naprej.

Ta pravilnik začne veljati naslednji dan po objavi v Uradnem listu Republike Slovenije.
