# Koeficienti rasti cen v Republiki Sloveniji, december 1999

Na podlagi prvega odstavka 19. člena zakona o državni statistiki (Uradni list RS, št. 45/95) Statistični urad Republike Slovenije objavlja


## K O E F I C I E N T E
rasti cen v Republiki Sloveniji, december 1999

1. Mesečni koeficient rasti cen industrijskih proizvodov pri proizvajalcih decembra 1999 v primerjavi z novembrom 1999 je bil 0,008.
2. Koeficient rasti cen industrijskih proizvodov pri proizvajalcih od začetka leta do decembra 1999 je bil 0,035.
3. Koeficient povprečne mesečne rasti cen industrijskih proizvodov pri proizvajalcih od začetka leta do decembra 1999 je bil 0,003.
4. Mesečni koeficient rasti cen življenjskih potrebščin decembra 1999 v primerjavi z novembrom 1999 je bil 0,008.
5. Koeficient rasti cen življenjskih potrebščin od začetka leta do decembra 1999 je bil 0,080.
6. Koeficient povprečne mesečne rasti cen življenjskih potrebščin od začetka leta do decembra 1999 je bil 0,007.
7. Koeficient povprečne rasti cen življenjskih potrebščin od začetka leta do decembra 1999 v primerjavi s povprečjem leta 1998 je bil 0,061.
