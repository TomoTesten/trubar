# Sklep o ukinitvi javnega dobra (SKLE)

Na podlagi 15. člena Statuta Občine Prebold (Uradni list RS, št. 52/13) in Sprememb in dopolnitev Statuta Občine Prebold (Uradni list RS, št. 45/14) je Občinski svet Občine Prebold na 13. redni seji dne 25. 1. 2024 sprejel

S K L E P

o ukinitvi javnega dobra

1. člen

S tem sklepom se ukine javno dobro na parcelah

1371/9 – k.o. 1006-Latkova vas ID 7359964

1371/11 – k.o. 1006-Latkova vas ID 7359966

1371/12 – k.o. 1006-Latkova vas ID 7359962

1371/13 – k.o. 1006-Latkova vas ID 7359963

1371/15 – k.o. 1006-Latkova vas ID 7372607

kot javno dobro.

2. člen

3. člen
