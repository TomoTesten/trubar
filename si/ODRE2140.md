# Odredba o dopolnitvi Odredbe o določitvi seznama tehničnih specifikacij o postopkih s področja motornih in priklopnih vozil (1. dopolnitev)

Na podlagi drugega odstavka 11. člena Zakona o motornih vozilih (Uradni list RS, št. 106/10) izdaja minister za promet


## O D R E D B O
o dopolnitvi Odredbe o določitvi seznama tehničnih specifikacij o postopkih s področja motornih in priklopnih vozil (1. dopolnitev)


### 1. člen

V Odredbi o določitvi seznama tehničnih specifikacij o postopkih s področja motornih in priklopnih vozil (Uradni list RS, št. 50/11) se v prilogi na seznam za vrstico s številčno oznako »TSV 601/00« doda nova vrstica, ki se glasi:

|          |   področje njene    |   začetek    |               |
|          |     veljavnosti     |   obvezne    |               |
|          |                     |   uporabe    |               |
