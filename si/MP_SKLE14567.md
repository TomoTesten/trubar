# Sklep o imenovanju občinske volilne komisije (SKLE)

o imenovanju občinske volilne komisije


### 1. člen

Did Mušinovič, namestnik predsednika, 1957, Podsmreka 5 P,

3. Marko Košir, član, 1968, Črni Vrh 31,

4. Andrej Malovrh, član, 1974, Pristava pri Polhovem Gradcu 5,
Boštjan Rihar, namestnik, 1971, Ul. Emila Adamiča 41, Dobrova.
