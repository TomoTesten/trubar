# Uredba o dopolnitvi Uredbe o razvrstitvi prepovedanih drog

Na podlagi drugega odstavka 2. člena Zakona o proizvodnji in prometu s prepovedanimi drogami (Uradni list RS, št. 108/99, 44/00, 2/04 – ZZdrI-A in 47/04 – ZdZPZ) izdaja Vlada Republike Slovenije


## U R E D B O
o dopolnitvi Uredbe o razvrstitvi prepovedanih drog


### 1. člen

V Uredbi o razvrstitvi prepovedanih drog (Uradni list RS, št. 49/00, 8/01 – popr., 49/01, 78/02, 53/04, 122/07 in 102/09) se v seznam skupine II. za zaporedno številko 173 doda nova zaporedna številka 174, ki se glasi:

»
+---------+------------+--------------------+
|Zaporedna|Prepovedana |Kemijsko ime        |
|številka |droga       |                    |
+---------+------------+--------------------+
|174.     |TAPENTADOL  |3-[(1R,2R)-3        |
|         |tapentadolum|-(dimetilamino)-    |
|         |            |1-etil-2-           |
|         |            |metilpropil] fenol  |
|         |            |                    |
|         |            |C(14)H(23)NO        |
|         |            |M(r) = 221,3        |
+---------+------------+--------------------+
                                           «.

Zaporedne številke prepovedanih drog skupine III. se ustrezno preštevilčijo.


### 2. člen

Ta uredba začne veljati petnajsti dan po objavi v Uradnem listu Republike Slovenije.
